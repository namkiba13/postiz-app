# Postiz Agent writing instructions

The writing block in `load.tools.service.ts` adapts selected guidance from:

- **Marketing Skills / social 2.3.2**, Corey Haines:
  https://github.com/coreyhaines31/marketingskills/blob/5e721d73ac85be8ba917d6a9ca9cb5bc98f02b80/skills/social/SKILL.md
- **Humanizer 3.1.0**, Siqi Chen:
  https://github.com/blader/humanizer/blob/225a6f39ac85f76ee48dbad772ea4abe4ed6c9d8/SKILL.md

Adapted on 2026-10-07 for the existing Mastra Agent: social drafting followed
by embedded editing in the same response, conversation-based brand context,
Vietnamese style guidance, and Postiz's existing tool/confirmation contracts.
These are selected instructions, not a runtime skill loader or the complete
upstream skill libraries. Updating an upstream repository does not change
the deployed prompt automatically.
